# 🧠 AI Image Generator (MERN Stack)

An AI-powered image generator built with the MERN stack. This application allows users to input prompts and receive AI-generated images using advanced machine learning models.

## 🚀 Features

- 🔍 Prompt-based AI image generation
- 💾 Save and manage generated images
- 👤 User authentication and dashboard
- 🌐 Full-stack MERN architecture
- 🎨 Beautiful UI built with React

## 🛠️ Tech Stack

### Frontend:
- React.js
- Tailwind CSS / Bootstrap (choose one based on your setup)
- Axios

### Backend:
- Node.js
- Express.js
- MongoDB (Mongoose)
- Cloudinary or Firebase (for image storage)
- OpenAI API / Stable Diffusion API (for image generation)
